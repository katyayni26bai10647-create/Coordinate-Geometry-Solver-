# GeoKit CLI

An efficient, lightweight **Python Command Line Interface (CLI)** engine designed for essential Cartesian coordinate geometry calculations. **GeoKit CLI** transforms standard algebraic formulas into instant console-based calculations, enabling quick evaluations of points, segments, and linear structures.

## 🚀 Key Features
* **Euclidean Distance Engine:** Calculates the precise straight-line spatial distance between any two Cartesian plots (x₁, y₁) and (x₂, y₂).
* **Bisection Matrix (Midpoint):** Resolves the absolute median midpoint parameters to balance geographic positions.
* **Gradient Identifier:** Determines structural line slopes directly from standard linear equations (dx + ey + f = 0).

## 🛠️ Installation & Setup

### Prerequisites
* **Python Runtime Environment** (Version 3.6 or later recommended).

### Running the App
1. Clone or download the repository files.
2. Ensure `geo_tool.py` is present in your working directory.
3. Launch your system terminal or command prompt and run:
   ```bash
   python geo_tool.py
   ```
4. Follow the interactive numbered prompt interface to run your calculations.
